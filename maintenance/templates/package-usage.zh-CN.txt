一、运行要求
------------
1. Windows 10 或 Windows 11。
2. TShock 6.2.x。
3. 自包含发布包不需要额外安装 .NET。
4. 管理器运行期不依赖 PowerShell、bat 或 cmd 脚本。

二、快速开始
------------
1. 解压部署包到固定目录，不要放在临时目录。
2. 打开 config.json，确认「服务器列表」指向正确的服务端目录。
3. 双击 PGame-TSManager.exe 启动管理器。
4. 在服务器列表选择目标服务器，使用“启动”或“全部启动”。
5. 首次部署后运行 PGame-TSManager.exe --selfcheck 检查目录和配置。

三、常用命令
------------
PGame-TSManager.exe --startall
    启动管理器并顺序启动全部服务器。

PGame-TSManager.exe --syncplugins
    只同步插件，不启动服务器。

PGame-TSManager.exe --selfcheck
    无界面自检，结果写入 selfcheck.txt。

PGame-TSManager.exe --nowindow
    强制无界面运行。

PGame-TSManager.exe --tool config-check "<服目录>"
    只读校验 TShock 中文键、REST 字段与 SSC 英文。

PGame-TSManager.exe --tool new-server --root . --name "<名字>" --port 7779 --rest-port 7880
    新建受管服务器。

PGame-TSManager.exe --tool script-audit --root .
    扫描并拒绝 .ps1/.bat/.cmd/.sh。

四、目录说明
------------
config.json          服务器列表和运行策略
Core                  TShock 运行时、依赖、数据、日志、备份和运行沙箱
Servers\Profiles      各服务器配置和 TShock 配置
Servers\Worlds        世界文件目录
Plugins              插件统一维护目录
README.md            项目说明
使用说明.txt         本文件

五、注意事项
------------
1. 管理器只读取配置并启动服务器，不会自动改写服务器自身配置。
2. 每台服务器加载哪些插件，以该服 config.json 的插件清单为准。
3. 不在插件清单中的插件会移入停用目录，不直接删除。
4. 世界文件、数据库、玩家数据和日志不应上传到源码仓库。
5. 管理器运行期逻辑全部在 C# 底层完成，不执行 PowerShell、bat 或 cmd 脚本。
6. SSC 保持英文；/help 保持原逻辑。
7. 服务器空人时管理器会自动压缩工作集，不关闭端口，玩家第一次进入不受影响。
