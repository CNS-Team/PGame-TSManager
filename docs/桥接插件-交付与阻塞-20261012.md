## 五、根因复盘（三个，全部实锤）

### ① TShock 插件**必须有 `[ApiVersion(2, 1)]`** —— 否则被静默跳过

用 Cecil 反编译 `HotReload.Core::LoadPluginFromDisk` 看到判定链：

```text
GetExportedTypes() → IsSubclassOf(TerrariaPlugin) → IsPublic → !IsAbstract
                   → **GetCustomAttribute<ApiVersionAttribute>() != null**   ← 缺这个直接 brfalse 跳过
                   → ApiVersion.Major/Minor 与 ServerApi.ApiVersion(2.1) 匹配（除非 ServerApi.IgnoreVersion）
```

`ServerApi.LoadPlugins`（启动加载）走的是同一套判定 —— 所以**没有该特性时：启动静默不加载、`/hr load` 报
"未找到有效的 TerrariaPlugin 子类"，两条路径都只是"看起来像插件不存在"**。
本次四个探针（V1/V2/V3 + TSMBridge）最初都没写该特性 ⇒ 全部被跳过；加上 `[ApiVersion(2, 1)]` 后
**最小插件立刻加载成功**（日志 `[P1] 无 Harmony 依赖`）⇒ 证据闭环。

### ② `Lib.Harmony 2.2.0` 在 .NET 9 上会**原生崩溃（0xC0000005 访问冲突）**

加载 TSMBridge 时服务器进程直接退出：`退出码 -1073741819 = 0xC0000005`。
2.2.0 早于 .NET 9 的 **W^X（写异或执行）强制**，写 JIT 代码页时触发访问冲突。
换成 **`Lib.Harmony 2.4.3`** 后：V2（只建 Harmony 实例）√、V3（PatchAll）√、TSMBridge（5 个 patch）√，
服务器全程存活 ✅。部署注意：`Core\bin\0Harmony.dll` 必须一并换成 2.4.3（2.4.3 ≈ 2.35 MB 单文件；运行时已有 的 MonoMod.* 1.2.3/25.x 满足依赖）。

### ③ 两个 patch 目标名要先查清（编译器/Cecil 当探针）

| 目标 | 实际签名/类型 | 踩过的坑 |
|---|---|---|
| `TShockAPI.Commands.HandleCommand` | `static bool (TSPlayer player, string **text**)` | 我按 `cmd` 命名注入 → Harmony 报 `Parameter "cmd" not found`；改用**位置参数 `__0/__1`** 后 √ |
| 日志 | **没有 `TShockAPI.Log` 类**；`ILog` 的实现是 `TShockAPI.TextLog` / `TShockAPI.SqlLog` | `AccessTools.TypeByName("TShockAPI.Log")` → "类型不存在"；且这两个类各有 `ConsoleError(string)` 与 `ConsoleError(string, params object[])` 两个重载 → 必须**显式给 `typeof(string)`**，否则 `Ambiguous match` |
