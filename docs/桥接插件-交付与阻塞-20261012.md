## 三、契约（给 Bot / 维度 / RPG 的现成结论）

```text
POST /tsm/plugins/bridge/events     插件 → TSM（仅 127.0.0.1 + X-TSM-Token）
  body: { "serverId":"0", "events":[ {"type":"player.joined","at":"...","data":{...}} ] }
  resp: 200 { ok:true, serverId, accepted:N }        （400: serverId_required / invalid_json）
GET  /tsm/bridge                    每服桥接状态快照（PascalCase，与 Control API 一致）
事件类型：bridge.hello / player.joined / player.left / world.saved / plugin.loaded /
          server.tick / server.stall / server.errors / command.slow / command.slow.count / server.reload
SSE：上述 type 原样进 ControlEventHub；其中 server.tick **常态不推**（每服 5 秒一条会淹），
     仅在 intervalMaxMs ≥ 250 时推 server.tick.high；其余照推。
契约版本不变（tsm.control.v1，纯新增端点与事件类型）。
```
